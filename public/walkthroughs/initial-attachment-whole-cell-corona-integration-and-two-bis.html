What batching and pruning change—and what they do not

A search slot is one direction/polarity problem with its own bounds and state. Batching runs many slots together; it does not replace their individual brackets with a shared answer.

  • Each step computes trial drives, marks eligible nodes, compacts them into a work list, evaluates charge, updates bounds, and updates saved node masks.
  • The tiled charge kernel distributes one candidate’s cells across threads and reduces their partial sums.
  • The host executes a predetermined number of steps. Finished slots produce no further work; the loop does not download intermediate bounds to decide when to stop.
  • First-search bound pruning removes a node failing at an accepted upper bound only when every precomputed flux weight for that node is nonnegative.
  • A negative weight disables that node’s bound pruning. The second search disables bound pruning altogether, but still uses the signed-field gate.

These guards matter because cell membership changes in jumps. With negative weights, adding a cell can reduce computed charge. The code still performs bisection: it does not scan for multiple inception intervals or prove that the returned threshold is the global minimum.

Monotonicity flags explicitly inspect every candidate’s weights for negative values.

def tet_radial_flux(point_0: warp.vec3d, point_1: warp.vec3d, point_2: warp.vec3d, point_3: warp.vec3d,
                    candidate_location: warp.vec3d):
    """Sum over the 4 faces of a tet of C_f = (f_hat . s_hat) A_f (s_hat taken at face centroids)."""
    flux = warp.float64(0.0)
    for opposite_vertex in range(4):
        # The face opposite vertex opposite_vertex, and that opposite vertex
        first = point_1
        second = point_2
        third = point_3
        opposite = point_0
        if opposite_vertex == 1:
            first = point_0
            opposite = point_1
        elif opposite_vertex == 2:
            second = point_0
            opposite = point_2
        elif opposite_vertex == 3:
            third = point_0
            opposite = point_3
        # Area vector (magnitude A_f); flip it if it points towards the opposite vertex (inward)
        area_vector = warp.float64(0.5) * warp.cross(second - first, third - first)
        if warp.dot(area_vector, opposite - first) > warp.float64(0.0):
            area_vector = -area_vector
        # Unit vector from the candidate node to the face centroid
        to_face_centroid = (first + second + third) / warp.float64(3.0) - candidate_location
        flux += warp.dot(area_vector, to_face_centroid) / warp.length(to_face_centroid)
    return flux

def bisection_step_count(lower_bound: float, upper_bound: float, relative_tolerance: float,
                         maximum_iterations: int) -> int:
    """Largest number of halvings that any slot of the shared bracket [lower, upper] can need.

    A slot stops when U − L <= tol · U. Its U is never below lower_bound, and the width after k
    halvings is (upper − lower) / 2^k, so k = ceil(log2((upper − lower) / (tol · lower))) halvings
    suffice; one more covers rounding of the midpoints. With lower_bound = 0 the bound is the
    iteration limit.
    """
    if lower_bound <= 0.0 or relative_tolerance <= 0.0:
        return int(maximum_iterations)
    width_ratio = (upper_bound - lower_bound) / (relative_tolerance * lower_bound)
    needed_halvings = math.ceil(math.log2(width_ratio)) + 1 if width_ratio > 1.0 else 1
    return int(min(maximum_iterations, needed_halvings))
