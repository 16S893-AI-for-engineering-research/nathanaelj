# 16.S983 AI Agents for Engineering Research - Portfolio

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Building

```bash
npm run build
```

## Deployment

This site is automatically deployed to GitHub Pages via GitHub Actions on push to `main`.

Visit: https://16s893-ai-for-engineering-research.github.io/nathanaelj/

## Project Structure

```
src/
├── pages/                 # Page routes (auto-generated by Astro)
│   ├── index.astro       # Homepage
│   ├── about.astro       # About Me
│   ├── projects/
│   │   ├── index.astro   # Projects listing
│   │   └── [slug].astro  # Dynamic project pages
│   └── dev-log.astro     # Dev log (will use markdown content)
├── content/              # Markdown content
│   ├── projects/         # Individual project markdown files
│   └── dev-logs/         # Dev log entries (markdown)
├── components/           # Reusable Astro components
│   ├── layout/
│   │   ├── Header.astro
│   │   ├── Footer.astro
│   │   └── BaseLayout.astro
│   ├── common/
│   │   └── (shared UI components)
│   └── interactive/      # Components with interactivity (React, etc)
├── styles/               # Global styles
│   └── globals.css       # Tailwind & global styles
└── lib/                  # Utilities and helpers
    └── (utility functions)
```
